# Contributing

**Monorepo:** [`everything-genai-rag-openclaw`](https://github.com/anthonyjohn17/everything-genai-rag-openclaw). Edit the matching top-level folder (`everything-gen-ai/`, `everything-rag/`, `everything-openai-whisper/`, `everything-openclaw/`, …).

## How to contribute

1. **Fork** [the repository](https://github.com/anthonyjohn17/everything-genai-rag-openclaw) and create a branch for your change.
2. **Scope your edit** to the right subfolder:
   - [`everything-gen-ai/`](everything-gen-ai/) — generative AI tools and services ([local guidelines](everything-gen-ai/CONTRIBUTING.md))
   - [`everything-rag/`](everything-rag/) — RAG patterns, frameworks, and links
   - [`everything-openai-whisper/`](everything-openai-whisper/) — Whisper ecosystem links
   - [`everything-openclaw/`](everything-openclaw/) — OpenClaw docs, agent templates, skills, and use cases
3. **Keep list entries consistent** with the style already used in that section (format, tone, trailing punctuation).
4. **Open a pull request** with a short description of what you added or fixed and why it belongs here.

## Ground rules

- Prefer **accurate, maintained links** and concise descriptions.
- Do not submit **undisclosed promotional** or off-topic content.
- For **security-sensitive** issues in upstream OpenClaw itself, use the process documented in [`everything-openclaw/explain-openclaw/`](everything-openclaw/explain-openclaw/) (for example, contact paths described there)—do not post exploit details in public issues here.

Thank you for helping keep this resource useful.
