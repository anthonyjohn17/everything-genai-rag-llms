# Contributing

**Monorepo:** [`everything-genai-rag-llms`](https://github.com/anthonyjohn17/everything-genai-rag-llms). Edit the matching top-level folder (`everything-gen-ai/`, `everything-rag/`, `everything-openai-whisper/`, `everything-llm-apis/`, …).

## How to contribute

1. **Fork** [the repository](https://github.com/anthonyjohn17/everything-genai-rag-llms) and create a branch for your change.
2. **Scope your edit** to the right subfolder:
   - [`everything-gen-ai/`](everything-gen-ai/) — generative AI tools and services
   - [`everything-rag/`](everything-rag/) — RAG patterns, frameworks, and links
   - [`everything-openai-whisper/`](everything-openai-whisper/) — Whisper ecosystem links
   - [`everything-llm-apis/`](everything-llm-apis/) — free and open LLM API providers
3. **Keep list entries consistent** with the style already used in that section (format, tone, trailing punctuation).
4. **Open a pull request** with a short description of what you added or fixed and why it belongs here.

## Ground rules

- Prefer **accurate, maintained links** and concise descriptions.
- Do not submit **undisclosed promotional** or off-topic content.

Thank you for helping keep this resource useful.
