# Contributing (`everything-openclaw/openclaw-agents/`)

**Path:** `everything-openclaw/openclaw-agents/` in [`everything-genai-rag-openclaw`](https://github.com/anthonyjohn17/everything-genai-rag-openclaw).

To propose a new agent:

1. Add a folder under `agents/<category>/<your-agent>/` with at least **`SOUL.md`** and **`README.md`**.
2. Register the agent in **`agents.json`**.
3. Open a **pull request** against `main` with a short description of what the agent does and how you tested it.

For **security** issues in **upstream OpenClaw** (not this documentation mirror), use the official disclosure process described at [docs.openclaw.ai](https://docs.openclaw.ai).
